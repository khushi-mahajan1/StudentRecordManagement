# Student Record Management System

## About the Project
The Student Record Management System is a web-based application developed to manage student information. It allows users to add, view, search, update, and delete student records.

## Features
- Add new student records
- View student records
- Search for students
- Edit student details
- Delete student records
- Simple and user-friendly interface

## Technologies Used
- Java
- JSP (JavaServer Pages)
- Servlets
- HTML and CSS
- Apache Tomcat 10
- File-based storage (without MySQL)

## Project Structure
- `src/main/java` - Java source files
- `src/main/webapp` - JSP pages and web resources
- `Student.java` - Student model
- `StudentServlet.java` - Handles student-related requests
- `StudentFileManager.java` - Manages file-based student data

## Requirements
- Java JDK
- Eclipse IDE
- Apache Tomcat 10

## How to Run
1. Import the project into Eclipse.
2. Configure Apache Tomcat 10.
3. Run the project on the server.
4. Open the application in your browser.
